# DevOps Project 3 - CI/CD Pipeline Basics

## Objective
Understand the fundamentals of Continuous Integration and Continuous Deployment using GitHub Actions.

## Project Structure

```text
devops-project3/
├── .github/
│   └── workflows/
│       └── ci.yml
├── app.py
└── README.md
```

## Workflow Description

This project demonstrates a basic CI pipeline using GitHub Actions.

### Pipeline Stages

1. Trigger on push to the main branch
2. Checkout repository code
3. Setup Python environment
4. Execute the application

## Technologies Used

- Git
- GitHub
- GitHub Actions
- Python

## Expected Result

Whenever code is pushed to the main branch, GitHub Actions automatically runs the workflow and executes the Python application.
